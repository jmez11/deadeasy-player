# Meta Horizon Store Listing Draft

## App Title
DeadEasy Player

## Short Description
Immersive VR cinema player for Meta Quest 3 with true stereoscopic 3D (SBS & Over-Under) playback.

## Long Description
DeadEasy Player is a lightweight, high-performance VR cinema player engineered specifically for Meta Quest 3. Built around libVLC and Meta Spatial SDK surface extensions, it provides hardware-accelerated playback with true per-eye stereoscopic rendering.

### Key Features:
- **True Stereoscopic 3D**: Supports Side-by-Side (SBS) and Over-Under (OU) modes with hardware per-eye depth rendering.
- **Smart 3D Auto-Detection**: Automatically identifies projection modes from standard filename tags (`.SBS.`, `.HSBS.`, `.OU.`, `.HOU.`).
- **Flexible Playback**: Enjoy 2D monoscopic videos, 3D movies, and local media files or external streaming links.
- **Intent Integration**: Seamlessly hand off video streams from web browsers, companion apps, or local network servers directly into your VR cinema screen.
- **Single-Instance Player**: New playback intents smoothly switch streams within your existing session without stacking multiple activities.
- **Broad Format & Codec Support**: Hardware decoding for H.264, H.265/HEVC, VP9, AV1, and multi-channel audio tracks powered by libVLC.
- **Clean, Minimal VR UI**: Intuitive controls built with Jetpack Compose, featuring scrub bar, audio/subtitle track selector, projection picker, and subtle volume indicators.
